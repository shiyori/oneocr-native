# モデルパッケージ形式

[简体中文](../zh-CN/model-format.md) | [English](../en/model-format.md) | [日本語](../ja/model-format.md)

既定の `oneocr-cjk-en.ocrpack` は一つの ONEOCRPK コンテナーです。SDK はモデルセッションの作成前にメタデータとファイルのハッシュを検証します。通常の利用でリソースディレクトリを展開する必要はありません。

64 バイトのヘッダーは、0–7 バイトに `ONEOCRPK`、8–15 バイトにリトルエンディアンのバージョンとフラグ、16–23 バイトに JSON インデックス長、24–31 バイトにデータ領域のオフセット、32–63 バイトにインデックスの SHA-256 を保存します。JSON は 64 バイト目から始まります。データ領域とファイル範囲は 64 バイト境界に揃え、ファイルオフセットはデータ領域の先頭を基準とします。メタデータは profile、元モデルのハッシュ、pipeline、各ファイルのサイズと SHA-256 を記録します。不正な名前、重複、範囲の重なり、ハッシュ不一致を拒否します。

既定パッケージには検出器、分類器、中日韓英の認識器と辞書を含みます。認識は元の CPU モデルグラフと結果の意味を保持します。

開発用コマンド `oneocr pack`、`inspect`、`unpack` はパッケージを作成・検査します。`oneocr export` は従来のディレクトリ bundle に対応します。Go ツールでは `Pack`、`ReadPackage`、`Unpack` を使用できます。これらは三つの画像操作とは別のパッケージ管理ツールです。アプリでは既定のインストール済みモデルをそのまま利用できます。
